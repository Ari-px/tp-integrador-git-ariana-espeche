# Guía Básica de Informática

## Descripción

Este proyecto consiste en una guía digital básica sobre conceptos y comandos relacionados con la informática. El objetivo es organizar información de manera sencilla y clara para facilitar su consulta.

## Objetivo

El objetivo del proyecto es recopilar conceptos básicos de informática y algunos comandos útiles, organizándolos en diferentes archivos dentro de un repositorio gestionado con Git y GitHub.

## Estructura del repositorio

* `README.md`: contiene la descripción general, objetivo y estructura del proyecto.
* `ENTREGA.md`: registra el proceso realizado durante el trabajo práctico.
* `proyecto/conceptos.md`: contiene conceptos básicos de informática.
* `proyecto/comandos.md`: contiene una lista de comandos útiles.
