## Descripción del proceso

Primero se creó una carpeta de trabajo y se inicializó el repositorio utilizando Git. Luego se creó la estructura inicial del proyecto con los archivos README.md, ENTREGA.md y una carpeta proyecto. Se fueron realizando diferentes modificaciones y registrando mediante commits con mensajes descriptivos. También se utilizó el historial de Git para comprobar los cambios realizados. Posteriormente se creará una rama de trabajo para realizar una mejora en la documentación. Finalmente, el repositorio será publicado en GitHub y se crearán una issue y una pull request.

## Dificultades encontradas

Durante el proceso inicial apareció un error relacionado con la identidad del usuario de Git. El problema se solucionó configurando el nombre y correo electrónico mediante `git config --global`.

## Reflexión final

El trabajo permite comprender el funcionamiento básico de Git para controlar versiones y registrar los cambios realizados en un proyecto. También permite practicar el uso de GitHub para publicar repositorios y trabajar con ramas, issues y pull requests.
